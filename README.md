# Web

Short description of the project.

## How we work (Scrum)

- **Sprints:** 2 weeks, tracked in the GitHub Project "Web Sprint Board" (Sprint iteration field)
- **Backlog:** GitHub Issues, refined before they enter a sprint
- **Workflow:** branch from `main` -> pull request -> review -> squash merge
- **Definition of Done:** see `.github/pull_request_template.md`

See [CONTRIBUTING.md](CONTRIBUTING.md) for details.
